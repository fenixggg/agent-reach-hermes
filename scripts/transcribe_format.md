# 转录文字稿格式化规范

## 执行者
Hermes 在收到 `transcribe.py` 输出的 raw.txt 后执行此格式化步骤。

## 输入
- `*_raw.txt` — Groq Whisper 输出的原始文字，无标点/分段
- `*_meta.json` — 视频标题、时长、来源URL

## 输出
- `*_transcript.md` — 格式化后的 Markdown 文件

---

## 格式化规则

### 1. 标题区

```markdown
# {视频标题}

> 来源：{URL}  |  时长：{X}m{Y}s  |  转录：Groq Whisper → DSv4Flash 润色
```

### 2. 正文结构

#### 分级标题
- 若原文有明确的新闻编号（一、二、三...或 1. 2. 3.），使用 `## {编号}. {主题概括}`
- 若原文有副主题，使用 `###` 三级标题
- 无明确编号时，用空行+自然分段即可

#### 列表/Bullets
- **列举因果关系、多个要素、统计数据**时，用 Bullet points
- 例如：
  ```
  **主要原因有三：**
  - 全球AI算力建设带动电子需求激增
  - 对美国出口暴涨97.7%（抢出口效应）
  - 去年同期基数较低
  ```

#### 加粗
- **关键数字、核心结论**加粗
- **专有名词首次出现**时加粗（如「**日清食品**」「**东方锆业**」）
- 示例：
  - 出口同比增长**45.3%**，远超预期的**29.7%**
  - 涉及已出货数量约**28.7万件**

#### 标点符号
- 全角标点（，。、：；？！——""《》）
- 句末加句号
- 列举项之间用顿号
- 引文用「」或「」

### 3. 段落控制
- 一个主题或一个完整事件/新闻条目 = 一个段落
- 段落之间空一行
- 同一段落内不同侧面用句号分隔
- 长段落（>8行）考虑拆成多段

### 4. 引文/对话
- 直接引语使用「」或加粗
- 例如：万斯直言：「一个只有900万人口的国家不可能指望靠一路杀戮就把每一道国家安全难题都砍干净。」

### 5. 量化呈现
- 百分比、金额、数字保持原样
- 大数字用逗号千分位分隔

### 6. 尾部
```markdown
---
*由 Agent Reach 转录工具自动生成 | DSv4Flash 润色*
```

## 示例

### 输入（raw.txt）
```
2026年6月21日 信息差 早差1. 当地时间6月19日 日本知名食品企业日清食品正式对外宣布旗下一款人气杯装素食产品日清酱汁炒面杯 也就是附带鸡肉汤味的日清酱油炒面杯面因生产过程中可能有蓝色合成树枝碎片混入食品 决定启动自主召回涉及已出货的数量约为28.7万件 销售范围覆盖日本全国事情的起因要追溯到2026年3月10日 日清的合作工厂 东日本明星诸事会社奇遇工厂当天,该工厂一条负责向产品中投入粉末酱料的设备发生了机械故障,设备某个部件破损后产生了最大约1厘米长的蓝色合成树枝碎片
```

### 输出（.md）
```markdown
## 1. 日清食品因异物混入紧急召回约28.7万件杯面

当地时间**6月19日**，日本知名食品企业**日清食品**正式对外宣布，旗下一款人气杯装素食产品——日清酱汁炒面杯（附带鸡肉汤味的日清酱油炒面杯面），因生产过程中可能有蓝色合成树脂碎片混入食品，决定启动自主召回，涉及已出货数量约**28.7万件**，销售范围覆盖日本全国。

事情的起因要追溯到**2026年3月10日**，日清的合作工厂「东日本明星诸事会社奇遇工厂」当天一条负责向产品中投入粉末酱料的设备发生机械故障，设备某个部件破损后产生了最大约**1厘米**长的蓝色合成树脂碎片，在故障排除前已随生产线混入部分产品。虽然故障设备当天完成紧急修理，但该时段生产的产品已流入出货渠道。
```
