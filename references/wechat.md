# 微信公众号搜索与文章提取 (WeChat Public Search)

基于搜狗微信官方数据源 (`weixin.sogou.com`)，专门解决 AI Agent 无法检索微信公众号文章的孤岛痛点。

---

## 1. 快速使用

### 搜索公众号文章 (默认返回 Markdown 列表)

```bash
python scripts/wechat_search.py "搜索关键词" --limit 5
```

### 搜索并输出结构化 JSON

```bash
python scripts/wechat_search.py "搜索关键词" --limit 5 --format json
```

## 2. 微信文章全文提取 (Fetch 工具兼容性测试结论)

获取到微信真实文章链接（`https://mp.weixin.qq.com/s?...`）后，各 fetch 工具的兼容性横评如下：

| 工具 | 速度 | 成本 | 提取质量 | 适用性与推荐 |
|:---|:---:|:---:|:---|:---|
| 🥇 **s_wechat_article.py** | ⚡ ~1.2s | 免费 (本地) | ⭐⭐⭐⭐⭐ (curl_cffi 伪装 Chrome TLS 指纹；正文分段+图片按原文顺序；无需 Cookie) | **微信直链第一首选**（2026-10-03 实测 3/3：产业长文/散文图集/行业老文） |
| 🥈 **Firecrawl scrape** | 🐢 ~3-5s | 消耗点数 | ⭐⭐⭐⭐☆ (依赖浏览器渲染，效果完整但速度慢、烧配额) | 备选兜底 |
| ⚠️ ~~better-webfetch~~ | — | 免费 | ❌ **微信直链已失效**（2026-10-03 实测：对搜狗签名直链返回 17KB "环境异常"拦截页，提取 0 字符——微信卡的是 JA3 TLS 指纹，httpx 过不了；且 Readability 对微信 js_content 嵌套 section 评分判废，即使取数成功也是 0 字符。**其它静态网页照常可用**，仅微信不可用） | **勿用于微信直链** |
| ~~curl + Jina Reader~~ | — | — | ❌ **已移除**（本机 443 不通，直连与走代理均 HTTP 000，2026-09-15 实测） | **不可用** |

### 最佳工作流
1. 调用 `python scripts/wechat_search.py "关键词" --limit 5` 获取真实微信 URL；
2. 选定目标文章后，用专用提取脚本拿全文（移植自 NewsCrawler 的 js_content 递归行走器，输出 bwf 风格 JSON 信封或 Markdown）：
   ```bash
   python <skill-path>/scripts/s_wechat_article.py "微信直链URL"              # JSON
   python <skill-path>/scripts/s_wechat_article.py "微信直链URL" --format md  # Markdown
   python <skill-path>/scripts/s_wechat_article.py "URL" --save-to out.json   # 落盘(无BOM)
   ```
3. 脚本连续 3 次重试仍报 `blocked` → 直链签名可能过期（搜狗链 2-3 天失效）或 IP 风控，重新搜索取新链再试。

**依赖**: 系统 Python 需 `curl_cffi`（已装 0.16.3）+ `lxml`。维护要点见脚本头部 docstring（impersonate 指纹轮换、js_content/data-src 拦截页指纹等）。

## 凭证存放位置

**微信搜索无登录态**（2026-09-08 核实 wechat_search.py 源码）：脚本走搜狗微信（weixin.sogou.com），自动初始化 session cookie，无账号体系。唯一风险是高频触发搜狗验证码——报错时等几分钟再试即可，没有凭证可配。

## 频率与时效

- **频率控制**：单次任务搜索间隔至少 1 秒，避免触发搜狗 IP 点选验证码
- **链接时效**：搜狗解析出的微信链接带 timestamp+signature 临时签名，有效期约 2-3 天，搜索后应及时提取或归档

## ⚠️ 微信「原文直链」还原问题（2026-09-12 完整诊断，结论：未解决）

**背景**：写报告时需要给微信来源配**可长期打开的原文章链接**。此事经完整排查，**结论是无法从搜狗稳定还原**。以下记录全部实验与结论，避免后人重复试错。

### 一、先明确：微信 permalink 本身永久有效，不存在"过期"

`https://mp.weixin.qq.com/s?__biz=...&mid=...&idx=...&sn=...` 是微信的永久链接形态。

**对照实验（同 IP、同一时段、间隔 60 秒背靠背）**：

| 测试对象 | 结果 |
|---|---|
| 微信官方生成的完整 perm 链接 | ✅ **打开，11109 字符全文** |
| 正文中"推荐文章"的完整配套链接 | ✅ **打开**（返回的是那篇推荐文章） |
| 我们自己拼的 perm 链接 | ❌ captcha，192 字符 |

→ **结论：链接形态永久有效。不是时效问题。**

### 二、真正的原因：搜狗只给"残缺件"，`sn` 与 `mid` 不配套

用手机 UA 抓搜狗中转页，能提取到 `__biz` 和 `mid`，但是：

1. **目标文章自己的 `sn` 被服务端抹空** —— 页面里是 `sn: "" || "" || ""`，`var sn = ""`
2. 页面里能正则抓到的 `sn`（32 位 hex）**属于正文中"推荐文章"**，与目标文章的 `mid` 不是一对

**实测三者对不上（决定性证据）**：

| 文章 | 搜狗给的 mid | 抓到的 sn 实际配对 mid | 是否配套 |
|---|---|---|---|
| 丝瓜汤文学 | 2653635754 | **2653633493** | ❌ |
| 高文苗论文 | 2651971787 | **2651971128** | ❌ |
| 表情包绑架 | 2655092862 | **2655092798** | ❌ |

把不配套的 `mid + sn` 拼起来访问 → 微信必然弹出人机验证（`mp/wappoc_appmsgcaptcha`），因为签名校验不过。

> **推广教训**：抓取时若一个签名/密钥字段的值是"从页面其他地方正则捞来的"，**必须先验证它与目标对象是否配套**，不能只看它格式对不对。格式合法 ≠ 内容对号。

### 三、试过并失败的方案（不要重复试）

| 方案 | 结果 |
|---|---|
| 直接拼 `__biz+mid+idx+sn` | ❌ captcha（sn 不配套）|
| 加 `&source=41#wechat_redirect` 后缀 | ❌ captcha（后缀不解决 sn 问题）|
| 用 `__biz+mid+idx`（不带 sn）| ❌ 微信要求 sn 才能定位文章 |
| 从搜狗中转页挖 `/s/xxx` 短链 | ⚠️ **部分文章页面里带，大部分没有**；挖到的短链实测能打开（如 `mp.weixin.qq.com/s/VwwCWFdpxzZj0dU47WXufA` 成功渲染南方周末 2026-03 文章），但覆盖率极低 |
| 等待冷却后重试 | ❌ 无效。已用对照组证明不是限流 |
| 从搜狗搜索结果页挖 permalink/短链 | ❌ **0/12 命中**（结果页里全是搜狗自己的中转链）|

### 四、唯一可用的兜底：搜狗搜索入口（但要知晓其局限）

```python
# 用「文章标题」构造搜狗微信搜索入口 —— 这是可长期打开的页面
url = "https://weixin.sogou.com/weixin?type=2&query=" + urllib.parse.quote(article_title)
```

**实测（7 篇样本）**：

| 指标 | 结果 |
|---|---|
| 无验证码 | ✅ 7/7 |
| 搜索结果页能打开 | ✅ 7/7 |
| **能搜到该文章** | ⚠️ **5/7**（2 篇搜狗直接返回"没有找到相关的微信公众号文章"）|
| 是原文直链 | ❌ **不是**，需多点一次跳转 |

**局限（必须在报告里如实标注）**：
- 命中率有限——搜狗索引不覆盖全部公众号文章（新号/小号常搜不到）
- 不是直链，体验为"搜索页 → 原文"
- 搜狗对搜索结果页也可能随时加验证码（本次测试时无，但已知其有 IP 点选验证码机制）

### 五、给报告写作的建议（本 skill 的推荐做法）

1. **优先用可验证平台**：把论证重心放在微博/小红书/知乎（这三者链接实测均可达），微信作为**佐证**而非核心
2. **微信来源标注格式**：`【公众号名】《标题》· 日期` —— 让读者能在微信内自行检索
3. **若必须给链接**：用上述搜狗搜索入口，并在脚注注明"搜索入口，非原文直链"
4. **绝不要**把搜狗临时中转链（含 `timestamp=`/`signature=`）写进交付物——2-3 天即失效

### 六、如果未来要真正解决

需要拿到**目标文章自己的 `sn`**。可行路径（未验证）：
- 用**微信客户端**打开文章，从分享链接/复制链接获取（含正确 sn）
- 使用带登录态的微信数据服务（付费第三方）
- 微信官方 API（需公众号主体资质）

## 📊 搜狗微信搜索 · 工具价值评估（2026-09-12 实测）

**一句话定位**：**"能搜到标题但不能给你链接、能查历史但查不了当下"的半残工具。**
它的价值全部来自**微信生态的封闭性**——没有替代品，所以哪怕是半个工具也得用。

### 实测数据总表（本机真实测试，非估算）

| 维度 | 实测结果 | 评价 |
|---|---|---|
| 搜索稳定性 | 24 个关键词全部返回，平均 **9.0 条/词**，零失败 | ✅ |
| 翻页能力 | page 1/2/3 各 10 条，正常 | ✅ |
| 返回字段 | title / author / publish_time / summary / sogou_link，**100% 完整** | ✅ 结构干净 |
| 验证码 | 全程 **0 次**（间隔 3–5 秒） | ✅ 低频可用 |
| **标题相关性** | **79%**（190 条中 151 条命中主题） | ⚠️ 约 1/5 噪声 |
| **时效性（追热点）** | `tsn=1`（一天内）→ **返回空页** | ❌ 硬伤 |
| 精确标题检索 | 完整标题搜，7 条结果，**第一条精确命中** | ✅ 能定位具体文章 |
| **冷门文章收录** | **2/7 篇**返回"没有找到相关的微信公众号文章" | ❌ 覆盖不全 |
| **原文直链** | **0/12** 能挖到 permalink/短链 | ❌ 致命短板 |
| 历史跨度 | 样本覆盖 **2016–2026** 共 10 个年份 | ✅ 沉淀好 |

### 优点（真实可用的部分）

1. **唯一能搜微信公众号全文的免费入口** —— 微信是封闭生态、无公开 API，搜狗是当前唯一免登录通道。**这个"唯一性"是它全部价值的来源。**
2. **元数据质量意外地好** —— `publish_time` 精确到秒（190/190 条都有）、`author`（公众号名）完整、`summary` 有摘要。**做时间线和来源标注时很有用**（本 skill 的报告日期就是这么来的）。
3. **长尾检索能力强** —— 精准标题能定位到具体文章。适合"我要找那篇具体文章"的任务。
4. **历史沉淀好** —— 2016–2026 都有收录，**做回顾性研究够用**。

### 缺点（必须知道的坑）

1. **致命：给不了原文直链** —— 只给 2–3 天失效的临时中转链；目标文章的 `sn` 被抹空，无法还原永久链接（详见上一节）。**所有微信来源都不能给读者一个可长期点击的链接**，这在交付报告时是硬伤。
2. **追不了热点** —— `tsn=1` 直接空页。按年统计：2026 年仅 25/190 条，且零星分布。**没有"最近 24 小时"能力**，与微博/知乎的实时性差距明显。
3. **噪声率高（约 20%）** —— 泛词信噪比低：「表情包」搜出《粉缤沙滩emoji表情包》《表情包:诡秘这张卡你拿着》等素材包；「emoji 文化」搜出《emoji@城中村，艺术装置设计》《瑞典想用 emoji 宣传文化》等跑题内容。
4. **覆盖率不全** —— 新号/小号/改名号常搜不到。
5. **无正文** —— 只有标题+摘要，正文需另抓 better-webfetch（两段式）。
6. **有验证码风险** —— 本次未触发，但高频访问会出 IP 点选验证码，批量任务必须限速 3–5 秒/次。

### ⚠️ Agent 使用须知（本 skill 的推荐做法）

**适合用的场景**：

| 场景 | 理由 |
|---|---|
| 找某篇**已知标题**的公众号文章 | 精准标题第一条命中率高 |
| 做**回顾性**长尾研究（2023 年前） | 历史收录好 |
| 拿文章的**元数据**（日期/公众号名） | 字段完整准确 |
| 抓正文内容 | 搜索定位 + better-webfetch 抓全文，两段式 |

**不适用的场景**：

| 场景 | 理由 |
|---|---|
| **追当下热点** | `tsn=1` 空页，无实时性 |
| **需要原文可点击链接** | 拿不到 permalink，只能用搜索入口兜底 |
| 泛词大批量采集 | 20% 噪声，必须人工过滤 |
| 覆盖所有公众号 | 收录不全 |

**操作纪律**：

1. **论证重心放微博/小红书/知乎**（三者链接实测均可达），微信只作**佐证**
2. **来源标注格式**：`【公众号名】《标题》· 日期` —— 让读者能在微信内自行检索
3. **若必须给链接**：用搜狗搜索入口 `weixin.sogou.com/weixin?type=2&query=<标题>`，并注明"搜索入口，非原文直链"
4. **绝不要**把搜狗临时中转链（含 `timestamp=`/`signature=`）写进交付物 —— 2–3 天即失效
5. **限速**：搜索间隔 ≥1.5 秒，批量任务 ≥3 秒，避免 IP 验证码
6. **泛词检索后必须过滤**：命中素材包/祝福图/展览宣传类内容的，直接剔除
